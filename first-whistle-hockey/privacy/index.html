Privacy Policy

First Whistle Hockey is a YouTube channel run by Red Rock Apps LLC. This page covers two things: this website page, and First Whistle tools, the private tool the owner uses to manage the channel on YouTube.

Effective 21 November 2026

01 — This page

This page collects nothing.

The First Whistle Hockey page on this site has no sign-up, no cookies and no analytics. It is hosted on GitHub Pages, which may log visits the way any web host does. The links on it go to YouTube, Facebook, Instagram and TikTok, which have their own privacy policies.

02 — The channel tool

A private tool with one user.

First Whistle tools is a command-line tool used by one person, the owner of the First Whistle Hockey channel, on their own computer. It has no public sign-up, no analytics and no advertising. Nothing it reads is sold. The rest of this policy is about that tool.

03 — What it accesses

The channel’s own YouTube data.

First Whistle tools uses YouTube API Services with one permission, to manage the signed-in YouTube account. With it, the tool reads and changes:

  • the channel’s videos and their settings: titles, descriptions, tags, captions, thumbnails, privacy and schedule
  • the channel’s playlists and basic channel details
  • comments on the channel’s videos, including each commenter’s public display name and the text of the comment

It does not access email, contacts, files or any other Google data.

04 — How it is used

To run the channel, and nothing else.

The information is used to upload, update and schedule the channel’s videos, to post and check the channel’s own comments, to read and reply to viewers’ comments, and to confirm that what is on YouTube matches the release plan.

Red Rock Apps LLC does not use it for advertising or profiling, and does not use it to train AI models.

05 — Where it is kept

On the owner’s computer.

The sign-in token that Google issues is stored in a file on the owner’s computer. Records of what the tool changed, and copies of some comments, are kept in the channel’s private project files and their private backups.

The owner may use an AI assistant to operate the tool. When that happens, information the tool displays can be processed by the assistant’s provider in order to run it.

Beyond that, the information is not shared with anyone.

06 — Removing access

How access and copies are removed.

The owner can remove the tool’s access at any time on Google’s account permissions page, and can delete the stored sign-in token.

If you commented on a First Whistle Hockey video, you can delete your comment on YouTube. To ask for a saved copy of a comment to be deleted, write to the address below.

07 — YouTube’s terms

This tool uses YouTube API Services.

Use of the tool is subject to the YouTube Terms of Service. Google’s handling of data is described in the Google Privacy Policy.

08 — Changes

If this changes, it changes here.

When this policy is updated, the effective date at the top of the page changes with it.
